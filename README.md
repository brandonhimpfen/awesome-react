> A curated list of resources for React, Next.js framework, state management engines, server components, UI component libraries, routing toolkits, and testing frameworks.

React is a declarative, component-based JavaScript library for building user interfaces across web, mobile, and desktop applications. Featuring a virtual DOM, unidirectional data flow, React Hooks, and Server Components, React powers high-performance Single Page Applications (SPAs), Server-Side Rendered (SSR) architectures, and cross-platform native interfaces. This list is intended for frontend engineers, full-stack developers, React architects, and UI/UX software leads.

## Frameworks & Server-Side Rendering

Full-stack production frameworks, static site generators, and edge-rendering engines for React applications.

- [Next.js](https://github.com/vercel/next.js) — The React framework for the web providing hybrid static and server rendering, React Server Components, and smart bundling.
- [Remix](https://github.com/remix-run/remix) — Full-stack web framework focused on web standards, progressive enhancement, and fast nested routing.
- [Gatsby](https://github.com/gatsbyjs/gatsby) — Open-source static site generator powered by React and GraphQL for high-performance websites.
- [Astro React Integration](https://github.com/withastro/astro) — Modern static and server-first web architecture framework allowing selective hydration of React components.

## State Management & Data Fetching

Global state containers, atomic state primitives, asynchronous caching engines, and GraphQL clients.

- [TanStack Query (React Query)](https://github.com/TanStack/query) — Powerful asynchronous state management engine for fetching, caching, and updating server state in React.
- [Zustand](https://github.com/pmndrs/zustand) — Small, fast, and scalable bare-bones state management solution using simplified hook APIs.
- [Redux Toolkit](https://github.com/reduxjs/redux-toolkit) — The official, opinionated, batteries-included toolset for efficient Redux development.
- [Jotai](https://github.com/pmndrs/jotai) — Primitive and flexible atomic state management engine for React inspired by Recoil.
- [SWR](https://github.com/vercel/swr) — React Hooks library for remote data fetching developed by Vercel utilizing Stale-While-Revalidate strategies.

## UI Component Libraries & Styling

Design systems, headless UI components, styling solutions, and animation toolkits built for React.

- [MUI (Material UI)](https://github.com/mui/material-ui) — Comprehensive suite of UI tools and production-ready components implementing Google's Material Design.
- [Radix UI](https://github.com/radix-ui/primitives) — Unstyled, accessible component primitives for building high-quality design systems and web apps.
- [shadcn/ui](https://github.com/shadcn-ui/ui) — Beautifully designed components built with Radix UI and Tailwind CSS that you can copy and paste into apps.
- [Framer Motion](https://github.com/framer/motion) — Production-ready motion library for React powering layout animations and gestures.
- [Chakra UI](https://github.com/chakra-ui/chakra-ui) — Simple, modular, and accessible component library giving you the building blocks to construct React applications.

## Routing & Navigation

Routing toolkits, URL state management engines, and schema-based form builders.

### Client & Full-Stack Routers

- [TanStack Router](https://github.com/TanStack/router) — Fully type-safe router for React applications featuring built-in search parameter management and data loading.
- [React Router](https://github.com/remix-run/react-router) — Declarative routing system for React applications across client, server, and React Native targets.

### Form & Input Management

- [React Hook Form](https://github.com/react-hook-form/react-hook-form) — Performant, flexible, and extensible form validation engine with minimal re-renders.
- [Formik](https://github.com/jaredpalmer/formik) — Declarative form management library for tracking values, handling validation, and managing submit events.

## Testing & Quality Assurance

Unit testing suites, component visualizers, end-to-end testing utilities, and mocking libraries.

- [React Testing Library](https://github.com/testing-library/react-testing-library) — Light-weight solution for testing React components encouraged to resemble actual user interaction patterns.
- [Storybook](https://github.com/storybookjs/storybook) — Frontend workshop environment for building UI components and pages in isolation.
- [Cypress React Component Testing](https://github.com/cypress-io/cypress) — Component test runner for mounting and testing React component trees inside modern browsers.
